# تدفق النقاط والمخزون

## السلسلة
المصنع (MG) → موزّع جملة → تاجر قطاعي → السباك

## الفكرة
1. فاتورة من المصنع تمنح نقاطاً قابلة للتوزيع على شبكة الجملة.
2. عند البيع عبر POS/توزيع، تُنشأ `InvoiceDistribution` من بائع إلى مشترٍ.
3. بعد التأكيد، تُمنح النقاط (`points_awarded`) وتُسجل في محفظة المشتري (`WalletAccount.balance_points`).
4. السباك يمكنه تحويل النقاط لرصيد نقدي ثم طلب سحب (`WithdrawalRequest`).

## مفاهيم مهمة
- `network_code`: رقم موحّد لربط الحسابات في الشبكة.
- مخزون الشبكة يُدار عبر خدمات مثل `NetworkInventoryService` وPOS للموزّع/التاجر.
- التوزيعات بحالة `draft` معلّقة؛ `points_awarded` تعني أن النقاط وصلت.
