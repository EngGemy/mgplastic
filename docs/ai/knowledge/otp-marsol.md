# OTP و Marsol (تشغيل)

## السلوك الحالي
- إرسال OTP عبر Marsol يعتمد على إعدادات الحساب.
- إذا كان حساب SMS غير موثّق قد يفشل مسار SMS؛ النظام يفضّل OTP API.
- `otp_code` في قاعدة البيانات قد يكون `NULL` عندما يُدار التحقق خارجياً عبر Marsol OTP — هذا متوقع في بعض التدفقات.

## تسجيل السباك
- بعد التسجيل قد تُرجع الـ API `requires_otp: true`.
- التحقق عبر endpoints: `verify-otp` / `resend-otp`.

## للأدمن
عند مشاكل الدخول بالجوال: راجع سجلات Marsol، حالة التحقق، وتأكد من تطبيع رقم الهاتف الليبي.
