# مخزن الدعوة — لوحة المخزن المركزي

واجهة Filament + مستخدم جاهز للمخزن الذي يستقبل الطلبيات، يحدّث المخزون، يدير رصيد النقاط، يطلب من المصنع، ويتعامل مع متاجر القطاعي (والجملة عبر نفس شبكة الـ wholesale).

| | |
|--|--|
| **المسار** | `/warehouse` |
| **الدور** | `wholesale_distributor` + `is_central_warehouse=true` |
| **API الموبايل** | نفس `/api/v1/mobile/distributor/*` |

---

## بيانات الدخول (بعد الـ seeder)

| الحقل | القيمة |
|-------|--------|
| الرابط | `https://mg-plastic.com/warehouse` (أو محلياً `/warehouse`) |
| الهاتف | `0910000001` |
| البريد | `warehouse@mg-plastic.com` |
| كلمة المرور | `Warehouse@2026` |

```bash
php artisan db:seed --class=CentralWarehouseSeeder
```

---

## ماذا يستطيع المخزن؟

| القدرة | من الواجهة |
|--------|------------|
| لوحة تحكم + رصيد النقاط | الصفحة الرئيسية — بطاقات إجمالي / موزّع / متبقي |
| طلب من المصنع مباشرة | الطلبيات → إنشاء طلب جديد (قناة `factory_to_wholesale`) |
| استقبال طلبيات القطاعي | تبويب الوارد في الطلبيات → تأكيد / شحن / تم التسليم |
| تحديث المخزون | استلام طلب المصنع + كاشير الصرف للقطاعي |
| شبكة القطاعي | تجار القطاعي — إضافة / ربط |
| فواتير وتوزيعات | موارد الفواتير والتوزيعات |
| واجهة المحل | متجري + منتجاتي (عرض بدون نقاط) |

---

## الفرق عن موزع الجملة العادي

| | مخزن الدعوة `/warehouse` | موزع جملة `/distributor` |
|--|---------------------------|---------------------------|
| العلم | `is_central_warehouse=true` | `false` |
| الهوية | مخزن مركزي معتمد | موزع جملة معتمد |
| اللون | أخضر زمردي | أزرق |
| اللوحة | لوحة نقاط بارزة في الأعلى | لوحة الجملة الاعتيادية |

كلاهما يستخدم نفس محرك الطلبات والمخزون والنقاط.

---

## الموبايل

تطبيق الجملة يعمل مع حساب المخزن لأن الدور `wholesale_distributor`:

- `GET /api/v1/mobile/distributor/dashboard`
- `GET /api/v1/mobile/distributor/points-panel`
- `POST /api/v1/mobile/distributor/orders` (طلب مصنع)
- باقي مسارات الجملة في [MOBILE_STORE_APP.md](./MOBILE_STORE_APP.md)

## ملاحظات تشغيل

1. غيّر كلمة المرور بعد أول دخول في الإنتاج.
2. الأدمن يوافق الحساب مسبقاً في الـ seeder (`is_approved=true`).
3. الدخول على `/distributor` بحساب المخزن يحوّل تلقائياً إلى `/warehouse`.
