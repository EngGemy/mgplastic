# أهم الموزعين + دعاية منتجات MG + حماية المرتجعات

## 1) حماية المرتجعات (Backend)

### من يطلب؟
| المسار | يطلب المرتجع | لا يطلب |
|--------|--------------|---------|
| قطاعي→سباك | **السباك فقط** | تاجر القطاعي |
| جملة→قطاعي | **تاجر القطاعي فقط** | تاجر الجملة |

استثناء الطلب: المخزن المركزي + المصنع (admin).

### من يقبل؟
- يقبل/يرفض **البائع الأصلي فقط** (الطرف الأعلى):
  - مرتجع سباك → محل القطاعي
  - مرتجع قطاعي → محل الجملة
- **ممنوع** على من طلب المرتجع قبول/رفض طلبه.
- المشرف يمكنه التدخل مع **audit**.
- كل قرار في `decided_by` / `decision_audit` + `security_audit_logs`.

## 2) أهم الموزعين

`GET /api/v1/mobile/featured-wholesalers` (عام)

```json
{
  "data": {
    "items": [
      {
        "id": 12,
        "name": "اسم العلامة",
        "brand_name": "…",
        "phone": "…",
        "network_code": "…",
        "logo": "https://…/storage/brand_logos/…",
        "logo_url": "https://…/storage/brand_logos/…",
        "featured_sort": 1
      }
    ]
  }
}
```

تفعيل من لوحة الأدمن → المستخدمون → موزع جملة → **أهم الموزعين** + ترتيب الظهور.

## 3) دعاية منتجات MG

| Method | Path |
|--------|------|
| GET | `/api/v1/mobile/product-promotions` |
| GET | `/api/v1/mobile/product-promotions/{id}` |

حقول العنصر: `title`, `subtitle`, `body`, `media_type` (`image`|`video`|`comparison`), `image_url`, `comparison_image_url`, `video_url`, `product_id`, `product_name`, `product_url`.

إدارة من الأدمن: **المحتوى → دعاية منتجات MG**.

---

## 4) تنبيه الكميات القليلة

ويدجت على لوحات: أدمن / جملة / قطاعي / مخزن الدعوة — popup + قائمة للمنتجات بمخزون ≤ 5.

---

## 5) كل الفواتير + إعادة الاستخدام

- تسمية التنقّل: **كل الفواتير**.
- إجراء **استخدام نفس الفاتورة**: ينسخ البنود لفاتورة جديدة ثم يمكن تعديل الكمية / إضافة أصناف.

---

## 6) النقاط في الـ API

- `points_per_unit` على الكتالوج / المخزون / معاينة المرتجع = `null`.
- يظهر للتطبيق **الإجمالي فقط** (`total_points` على الطلب/المرتجع/المحفظة).
